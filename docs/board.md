# プロジェクト一覧・ボード・設定

## 画面

| ルート | 画面 | 内容 |
|---|---|---|
| `#/` | プロジェクト一覧 | カード(進捗、締切、最終更新。最終更新の新しい順)。カードの上に締切パネル(下記)。新規作成はタイトル・締切・メモを入れる(締切とメモは任意。タイトルは空欄でもよく、そのときは「無題のプロジェクト」になる)。作ったプロジェクトには「全体」レーンだけがある |
| `#/p/:id` | ボード | ツールバーのタブで「ボード」と「アレンジ」を切り替える。「全体」レーンを左端に固定し、セクションのレーンを横に並べる。上部にセクション一覧(チップ)があり、構成を俯瞰でき、押すとそのレーンへジャンプする。着手したタスクがあれば、下にガントチャートが出る。スマホではレーンを縦に積む(ガントチャートは出さない) |
| `#/p/:id/arrange` | アレンジ | [arrangement.md](arrangement.md) |
| `#/settings` | 設定 | UIテーマ(システム / ライト / ダーク)、音源(SoundFont / DLS のファイル。このブラウザだけ)、アレンジ画面の「編集から 〜」を出し始める分数(このブラウザだけ)、保存先の表示とログアウト、JSONのエクスポート/インポート |

- 画面をまたぐヘッダーは持たない。設定へはプロジェクト一覧の右上の歯車(`settings`)からだけ行く。ほかの画面(ボード、アレンジ、設定)は、それぞれの左上の「←」で一覧へ戻る。

## 締切パネル(プロジェクト一覧)

- 締切のある未完了のプロジェクトを締切の近い順に、「リスト」か「タイムライン」で見せる。どちらを出すかはタブで選び、ブラウザに覚える。全タスク完了のプロジェクトと締切なしは出さない。出すものがなければパネルごと出さない。
- リストは日付・曜日・タイトル・残り日数・作業日の列を全行で同じ幅に揃え、日付と数字は右寄せにする。締切日は曜日を併記する(「10/16(金)」。年は出さない。締切の近い順に並ぶので、12月のあとの1月は来年と分かる)。
- 「あと◯日」に、そのうちの土日の日数を「作業日」として併記する(土日に作業する場合の目安。「あと9日(4作業日)」。数える範囲は「あと◯日」と同じで、今日は含めず締切日は含める。今日が締切のときと超過のときは出さない)。
- 締切の表示(一覧のカードとボード):残り日数を出す。3日以内は強調、過ぎたら超過日数を赤で出す。全タスク完了なら日付だけ。

## ボードでできること

- ステータス切替(丸をクリックで 未着手 → 作業中 → 完了 と循環。保存を待っている間は丸が回る)、「未完了のみ」フィルタ
- レーン末尾のクイック入力(Enterで連続追加)
- タスクのドラッグ(レーン内の並べ替え、レーン間の移動)、セクションのドラッグ(ヘッダーを掴む)
- セクションの追加(レーン間の「+」または末尾のボタン)。名前を入れて、空のセクションを足す
- セクションの名前変更、複製、折りたたみ、削除
- セクションの名前は重なってもよい(レーンは内部の id で見分ける)。追加でも複製でも、名前に番号は振らない(複製は元と同じ名前)
- タスクの行には、タイトルの下にメモの先頭を1行で出す(改行は空白に詰め、入らない分は … で切る。全文は行の title)
- タスク詳細(PCは右ドロワー、スマホはボトムシート)で編集・削除。着手後は開始日を、完了後は終了日も、ここで修正できる。メモの欄は内容に合わせて伸び、下の削除ボタンがドロワーの中に見えたままの高さで止まって、それより長い分は欄の中でスクロールする(クリップ詳細の詳細欄も同じ。手で高さは変えられない)
- タスク詳細でリファレンス(曲名)を付ける・外す。ツールバーの音符のボタンで、プロジェクトのリファレンスの一覧(名前順。見るだけ。どのタスクに付いているかは出さない)を出す
- レーンとタスクの削除は、トーストから直前の1回を元に戻せる

## 知っておく挙動

- **タスクの開始日・終了日**は実績で、ステータスを変えたときに自動で入る。作業中にすると、開始日が空なら今日が入る。完了にすると終了日に今日が入る(未着手から直接なら開始日も今日)。完了を取り消すと終了日が消え、未着手に戻すと開始日も消える。丸のクリックは 未着手 → 作業中 → 完了 → 未着手 と循環するので、誤って完了にしたものを作業中へ戻すと、開始日は今日に置き換わる(必要なら手で直す)。ボードのタスク一覧には出さない。
- **日付の修正**はタスク詳細で行う。未着手では日付の欄が出ず、作業中は開始日、完了は開始日と終了日が出る。終了日を開始日より前にはできない(保存せずに元の値へ戻す)。欄を空にすることはできる。
- **ガントチャート**(作業の記録。予定ではない。表示のみ)に出るのは、作業中か完了で、開始日のあるタスク。作業中のものを上にして、セクションをまたいで開始日の早い順に並べる。
   - 1件もなければ領域ごと出ず、ボードが全高になる。高さは行数に合わせ、多いときは画面の半分までで、中でスクロールする。上端のつまみをドラッグすると高さを変えられる(上下の矢印キーでも動く。ダブルクリックで元に戻る)。画面の半分より高くはならない。決めた高さは、そのブラウザの localStorage に覚える(全プロジェクト共通)。
   - バーは開始日から終了日まで。色はステータスで塗り分け、作業中はアクセント色(青)、完了は灰色(セクションの色は使わない。セクションは行の左に名前で出す)。作業中のものは今日まで伸ばし、右端をぼかす。終了日を空にした完了タスクは、完了した日で止める。
   - 1日が1列の固定幅で、横にスクロールする(出た最初は今日が見える位置に合わせる)。今日の列と、締切の日(列の右端に線)に印が付く。範囲は、いちばん早い開始日の3日前から、今日・締切・いちばん遅い終わりのうち最も遅い日の3日後まで。「未完了のみ」は効かない(記録なので、完了した行も残す)。
   - まずはボードとの上下分割で作ってある。不便なら、タブなどでタスク一覧と切り替える形に変える。
- **リファレンス**(参考にする楽曲の曲名。タスクごとに複数。曲全体のものは「全体」レーンのタスクに付ける。ボードのタスク行には出さない)は、タスク詳細の入力欄に曲名を打って Enter で足し、チップの × で外す。
   - 打っている間は、同じプロジェクトのタスクに付いている曲名から、合うものを候補に出す(よく使っている順。前方一致を先に、部分一致を後に。そのタスクに付いているものは出さない)。↑↓ で選んで Enter か、クリックで決める。打っている間の候補は8件まで。欄を押すか、空のまま ↓ を押すと、登録済みの曲名(そのタスクに付いているものを除く)をすべて候補に出す(一覧の中でスクロールする)。
   - 全角・半角、大文字・小文字、空白、記号の違いしかない曲名は同じ曲とみなし、既にある表記に揃えて足す(「ｌｅｍｏｎ」→「Lemon」)。打ちかけのまま欄を離れたり閉じたりしても、その曲名は足される。日本語入力の変換を確定する Enter では足さない。
- **セクションの複製**:リファレンスは引き継ぐ。日付は引き継がない(コピー先のタスクは未着手・日付なし)。連動タスクはコピーしない。
- **同じ内容のセクション**(サビ、サビ2、サビ3)は、別々のレーンとして持つ。まとめて変えたいときは、1本を直してから残りを消し、「複製」で作り直す。
- **セクションの色**は保存していない。表示のたびに、並び順の先頭から1本ずつパレット(系統の違う9色(Tailwind の500)と、それぞれを明るくした9色(同300))の色を割り振る。名前は見ないので同じ名前のセクションも別の色になり、名前を変えても色は変わらない。セクションを並べ替えると色も入れ替わる。19本目からはパレットの先頭に戻る。
- **セクションの削除**:そのレーンの連動タスクと、それを指すセクションマーカーも消える(確認ダイアログに件数が出る)。元に戻すと、状態ごと戻る(その間に同じ小節へ別のマーカーを置いていたら、そちらを残す)。

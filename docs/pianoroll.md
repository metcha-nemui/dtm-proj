# ピアノロール

アレンジ画面のクリップをダブルクリック(端でもよい。またはクリップ詳細の「ピアノロールで編集」)で、画面の下に開く。開いている間は、クリップを押すとそのクリップに切り替わる。拍子は 4/4 固定。

## 編集

- 空いているところを押すとノートを置き、そのままドラッグで動かせる。ノートを掴むと移動(上下で音の高さ)、右端を掴むと長さを変える。右クリックで消す(押したままなぞると続けて消す)。
- タッチ(指で押す画面。pointer: coarse)では、グリッドの上の指はスクロールにせず、すぐノートの操作にする。
   - 空いているところをタップするとノートを置く(置いたノートは選ばない。選んでいるノートがあれば、置かずに選択を外す)。指を動かすと、置いたノートをそのまま動かす(離したあとは選ばない)。少し長押ししてから動かすと、囲んだノートを選択に足す。
   - ノートをタップすると選択に足す / 外す。ノートを掴んで動かすと、選んでいるノートをまとめて移動する(選んでいないノートなら、それだけを選んで動かす)。指が 8px 動くまではタップとして待つ。
   - ヘッダーの伸縮モード(`unfold-horizontal`)を ON にしている間は、ノートのどこを掴んでも、動かすと長さを変える(選んでいるノートをまとめて)。この間はノートを置かず、動かさず、囲んで選ぶこともしない。ノートの左右 16px 以内の空いているところ(同じ高さ)を押しても、そのノートを掴む(タップなら選択に足す / 外す。いちばん近いノート)。OFF の間は、タッチでは長さを変えられない。
   - スクロールは、横はグリッドの下の太いスクロールバー(つまみをなぞる。つまみの外を押すと、そこへ飛ぶ)、縦は鍵盤の上をなぞる(離したらその場で止まる)。ブラウザのスクロールバーは出さない。
   - 鍵盤は、動かさずに離したときに鳴らす。
   - ノートを選んでいる間は、グリッドの右端に十字キーを出す。←→ でグリッド1つ分、↓↑ で半音、選んだノートを動かす(矢印キーと同じ)。押し続けるとくり返し動き、離したときに保存する。
- ノートを選んでいる間は、ヘッダーにゴミ箱のボタン(`trash-2`)が出る(Delete と同じ)。
- 元に戻す・やり直す:Ctrl+Z で元に戻し、Ctrl+Y か Ctrl+Shift+Z でやり直す。タッチの画面では、ヘッダーのボタン(`undo-2` / `redo-2`)でも行う。1回の保存(ドラッグなら離すまで、十字キーなら離すまで)を1回として、クリップごとに 100 回まで戻せる。戻したあとは選択を外す。ほかのクリップに切り替えても、それぞれの履歴は残る(アレンジ画面を離れると消える)。
   - 次のときは、そのクリップの履歴を捨てる(古い状態に戻すと、位置がずれたりクリップからはみ出したりするため):ピアノロールの外でノートが変わったとき(.mid の読み込み、クリップの左端の伸縮、ほかの端末での変更)、クリップの長さが変わったとき、保存に失敗したとき、クリップを消したとき(「元に戻す」でクリップを戻しても、履歴は戻らない)。
- ノートはクリップの範囲(左端〜右端)からはみ出すようには動かせない(ドラッグでも矢印キーでも。置くノートや長さの変更も、右端で止まる。もともとはみ出しているノートは、それ以上外へ動かさない)。
- Shift+クリックで複数選択、Ctrl+ドラッグで囲んだノートを選択(Ctrl+Shift+ドラッグで選択に足す)、Ctrl+A で全選択。選択中のノートはまとめて、Delete で削除、↑↓ で半音(Shift か Ctrl で1オクターブ)、←→ でグリッド1つ分(Shift か Ctrl で1小節)動かす。Esc で選択を外し、選択がなければ閉じる。
- コピー・切り取り・貼り付け:選んだノートを Ctrl+C でコピー、Ctrl+X で切り取り(コピーしてから消す。元に戻すと1回で戻る)し、Ctrl+V で貼り付ける。貼り付ける位置は、再生を始める位置(赤い印)。印がクリップの外なら、クリップの頭。コピーしたノートの並び(いちばん早いノートからの位置と高さ)をそのまま置き、貼り付けたノートを選んだ状態にする。クリップの右端より後ろで始まるノートは貼らず(数を知らせる)、右端をまたぐノートは右端で切る。コピーはクリップや画面を切り替えても残る(ページを読み込み直すと消える。OS のクリップボードは使わない)。再生中は貼り付けできない(コピーと切り取りはできる)。
- 置くノートの長さは、最後に触ったノートの長さ。グリッドは 1/4〜1/32 と、それぞれの3連、なし から選ぶ(ブラウザに覚える)。いちばん細い縦線はグリッドの細かさに合わせる(「なし」なら 1/16)。Alt を押しながらだとグリッドに合わせない。置くノートのベロシティは、最後に触ったノートのもの(初めは 100)。
- ノートの高さ(1音の縦の幅)は 8〜32px、1拍の幅は 16〜256px(既定は 64px)の間で変えられる。マウスでは、ホイールを押しながら回すとノートの高さ(1目盛りで 2px)、Shift も押しながらだと1拍の幅(1目盛りで 1.25 倍)。指の間やポインタの位置にある音・時間は、同じ位置に残す。ノートの高さの既定は PC で 12px、タッチの画面で 20px。どちらもブラウザに覚える。
   - タッチでは2本の指でピンチする。鍵盤の上ならノートの高さ、横のスクロールバーの上なら1拍の幅を変える(2本とも同じところに置く)。2本目の指を置くと、1本目の指でしていたスクロールはやめる(スクロールバーで飛んだ位置は元に戻す)。ピンチの指を1本離したら、残った指は離すまで何もしない。
- 同じ高さ・同じ位置で始まるノートが重なっていると(長さが違っても)、どちらも赤く出す。重なりはそのまま保存するので、気付いたら片方を消す。動かして重ねても、選択は動かしたノートだけに残る。

## ベロシティ

- グリッドの下の段(縦にスクロールしても下端に残る)に、ノートの頭の位置で縦棒として出す。ノートも、ベロシティが小さいほど薄く出す。
- 段を押して上下になぞると、なぞった位置の棒をその高さのベロシティ(1〜127)にする(FL Studio と同じ。和音のように同じ位置の棒はまとめて変わる)。選んでいるノートがあれば、選んでいるものだけを変える。
- Alt を押している間は既定値(100)にする。Shift を押してから段を押すと、押した位置から今の位置まで直線で描く(線の外に出た棒は元に戻る)。なぞっている間は、段の左に値が出る。離したら保存する。試し弾きの音も、そのノートのベロシティで鳴らす。

## 表示

- 高さは上端のつまみをドラッグ(またはフォーカスして ↑↓)で変える。上はツールバー(再生・BPM)の下端まで(複製の置き場所を選んでいる間は、その案内の下まで)。ダブルクリックで既定(画面の約半分)に戻す。変えた高さはブラウザに覚える。画面を縮めたり回したりして入り切らなくなったら、ピアノロールの方が縮み、ツールバーは隠れない。
- スマホの横持ち(縦が 500px 以下のタッチの画面)では、アレンジのツールバーの上に重ねて、画面全体に出す(上端のつまみは出さない。縦持ちや PC の高さはそのまま)。再生はヘッダーのループ再生で行う。クリップ詳細・メニューは、その上に開く。
- 鍵盤を押すか、ノートを置いたり動かしたりすると、その音を短く鳴らす(音源を読み込み済みのときだけ。読み込み前なら、読み込みを始めるだけで鳴らさない)。鍵盤の表記は 60 = C4。
- グリッドの行は、鍵盤の白黒ではなくスケール(アレンジ画面の「スケール」の段)で塗り分ける(スケールの外の音を暗く、主音を少し色付きに。鍵盤は実際の白黒のまま)。クリップの途中で転調していれば、転調の位置(縦の線)から塗り分けを変える。ヘッダーには、クリップに掛かるスケールを「C メジャー → A マイナー」のように出す。表示だけに使い、ノートの置き場所は制限しない。
- オニオンスキン:ヘッダーの重なりのボタン(`layers`)を押すと、ほかのトラックの、同じ時間に鳴るノートを灰色で薄く重ねて出す(編集するノートの下に敷く。押せない。クリップの範囲の外に出ているノートは出さない)。隣のボタン(`list-checks`)のメニューで、出すトラックを1本ずつ切り替える(メニューは閉じないので続けて切り替えられる)。どちらも覚えておかず、閉じた状態から開くたびに「全体 OFF・各トラック ON」に戻る(開いたままクリップを切り替えたときは引き継ぐ)。

## 再生

- ヘッダーの再生ボタンは、そのクリップだけを頭から鳴らし、右端まで来たら頭に戻ってくり返す(FL Studio のパターン再生と同じ。止めるまで続く)。鳴らすのはそのクリップのノートだけで、トラックのミュート・ソロに関わらず鳴らし、ほかのトラックは鳴らさない。
- ループ中はボタンが停止の形になり、押すと止まる(ツールバーの停止やスペースキーでも止まる)。ループ中のノート・音色・音量・パンの変更はすぐ効く。クリップを動かしたり伸縮したりすると、新しい範囲で、クリップの中の同じ位置から鳴らし直す。クリップを消すと止まる。
- 上端の小節番号の段を押すと、再生の開始位置が変わる(いまのグリッドの単位で、押した位置を切り捨てる。グリッドが「なし」なら 1/16。拍の途中の位置は、再生ボタンの title に「3小節目の2.5拍目」のように小数で出る。印はアレンジのルーラーにも出る)。ループで鳴らしている間に押すと、ループのまま、その位置から鳴らし直す。

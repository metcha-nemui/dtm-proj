# アレンジ

プロジェクトごとの、DAW のアレンジ画面のような別ページ(`#/p/:id/arrange`。ボードとタブで切り替える)。トラックを縦に並べ、クリップ(名前と詳細とノート)を1小節単位で置く。音声ファイルを1つ鳴らすオーディオトラックも置ける。ピアノロールは [pianoroll.md](pianoroll.md)。

- 上端に小節番号のルーラー、スケールの段、セクションマーカーの段、その下にトラックを縦に並べる。縦横にスクロールし、トラック名の列は左に、ルーラーとマーカーは上に残る。
- ツールバーの先頭(←、プロジェクト名、リファレンスの一覧、プロジェクトのメニュー)はボードと同じで、ボード / アレンジのタブが切り替えで動かない。
- スマホ(タッチで、縦か横が狭い画面)では、縦の場所を確保するため全画面(通知バーとナビゲーションバーを隠す)で使う。ボードの「アレンジ」タブを押したときに全画面に入り、ほかの画面へ移ると戻す。ブラウザは操作の中でしか全画面を許さないので、再読み込みしたときや、戻るジェスチャーで全画面が外れたときは、ツールバーの右端のボタン(`maximize` / `minimize`)で出入りする(このボタンはタッチの端末で、全画面にできるときだけ出る。iPhone の Safari では出ない)。
- MIDI は最低限の下書き用。拍子は 4/4 固定、テンポはプロジェクトに1つ(BPM。テンポチェンジなし)。トラックは1本につき1音色(General MIDI。ドラムのトラックはドラムキット)と音量・パン、ミュート・ソロ、リバーブの ON / OFF だけを持ち、CC やオートメーションは持たない。DAW へは .mid か、音源で鳴らした WAV で渡す(ブラウザから DAW へのドラッグは FL Studio が受け取らなかったのでやめた)。録音はしない。

## トラック

- 見出しには、上から順に番号(1, 2, …)を出す。表示のためだけのもので、保存しない(並べ替えると振り直す)。見出しにホバーすると、番号の場所が並べ替えのつまみのアイコン(`grip-vertical`)に変わる。
- トラック名の列の幅は、いちばん長い名前に合わせる(短ければ 216px のまま。長くても全角10文字が入る幅までで、それより長い名前は … で切る)。スマホ幅では 168px で広げない。
- 追加(下端の「トラックを追加」。名前が空なら「Track」)、トラックのメニュー(`ellipsis-vertical`)の名前変更・削除(クリップと、その連動タスクも消える。確認ダイアログに件数が出る。トーストから元に戻せる)、並べ替え(見出しを掴む)。
- **トラックの音**:トラック名の下の音色名を押すと開くダイアログで、General MIDI の音色、ドラム(10ch で鳴らす)、ドラムキットを変える。ダイアログの中身が長くてスクロールしても、下の「キャンセル」「保存」はいつも見えている(どのダイアログも同じ)。新しいトラックはピアノ・音量100・パン中央(ドラムキットは Standard)。
   - ドラムキットはセレクトボックスで、GS の並びの9つ(1. Standard、9. Room、17. Power、25. Electronic、26. TR-808、33. Jazz、41. Brush、49. Orchestra、57. SFX。番号は 10ch のプログラム番号で、gm.dls が持つのもこの9つ)から選ぶ。選ぶと、そのキットのスネアを短く鳴らす。ドラムのトラックでは、音色の代わりにキットの番号を 10ch にプログラムチェンジで送る(再生でも .mid の書き出しでも。バンクセレクトは送らない)。音源にない番号のキットは、音源(spessasynth)が別のキットで鳴らす。一覧にない番号を持つデータ(手で書き換えたものなど)は、その番号も選べるように出す。
   - 音色はコンボボックスで選ぶ。閉じているときはセレクトボックスの見た目で、選んでいる音色(「1. Acoustic Grand Piano」)を出す。押すと、ボタンの下(入り切らなければ上の、広い方)に、ボタンと同じ幅のドロップダウンを開き、絞り込みの欄と音色の一覧を出す(スマホの横持ちでも画面に入るように)。一覧は系統(ピアノ、ギター、ストリングス…の16系統)の見出しと音色を上から下へ流し、入り切らない分を隣の列へ折り返して、横にスクロールする(スマホ幅でも同じ)。開くと、選んでいる音色が見える位置までスクロールし、絞り込みの欄にフォーカスを当てる(スマホでは当てない)。音色を押すと、選んで、その音色で C4 を短く鳴らす(トラックの音量・パンで。音源の読み込み前と再生中は鳴らさない。ドラムのトラックでも、音色の音で鳴らす)。ドロップダウンは閉じないので、続けて聞き比べられる。閉じるのは、ボタンをもう一度押す・外を押す・Esc(Esc はドロップダウンだけを閉じ、ダイアログは閉じない)。開いている間に画面の大きさが変わったり、ダイアログがスクロールしたりしたら、置き直す。絞り込みは番号・音色名・系統名の部分一致(空白で区切ると、すべてを含むもの。全角・半角、大文字・小文字は区別しない)。欄で Enter を押すと、絞り込んだ先頭の音色を選ぶ。音色のダブルクリックは、選んでそのまま保存。
- **音量・パン**:音色名の右のつまみ。上下にドラッグで変え(Shift を押しながらだと細かく)、ダブルクリックで既定値(音量100・パン中央)に戻す。フォーカスがあれば ↑↓←→ でも1ずつ(Shift で10ずつ)動く。ホイールでは動かない(縦スクロールとぶつかるため)。動かしている間もすぐ音に効き、離したら保存する。値はつまみの title(「パン: R10」など)に出る。
- **ミュート・ソロ**:ミュート(`volume-x`)とソロ(`headphones`)のボタンがトラック名の横にある。ソロのトラックがあればソロのものだけを、なければミュートしていないものを鳴らす(ソロはミュートより強い)。ON のボタンは塗りつぶす(ミュートは赤、ソロは青)。鳴らないトラックはクリップを薄く出す。トラックに保存する。.mid の書き出しには効かない(全トラックを出す)。WAV の書き出しには効く。トラック名の列の上(ルーラーの左の角)の「ミュート・ソロ解除」で、全トラックのミュート・ソロをまとめて外す(どれも ON でなければ押せない)。
- **リバーブ**:パンのつまみの右のボタン(左右に弧を重ねた自作のアイコン)で ON / OFF を切り替える。ON のボタンは薄いオレンジで塗る(ON のトラックが多いので、ミュート・ソロより控えめにする)。新しいトラックと、項目のない古いデータは ON。ON のトラックは、再生のときにリバーブのセンド量(CC91)を 40(GS のリセット時の値。spessasynth の初期値は 0 で掛からないため)にし、OFF なら 0 にする。リバーブ本体(種類・残響時間・リターンの量)は spessasynth の既定のまま。センド量を変える画面はない。音色・ピアノロールの試し弾きにも効く。トラックに保存し、ミュート・ソロと同じく再生中に切り替えてもすぐ効く。このアプリの再生だけに使い、.mid の書き出しには CC91 を入れない。

## オーディオトラック

- 音声ファイル(WAV・MP3・OGG・FLAC・M4A など、ブラウザがデコードできるもの)を1つだけ鳴らすトラック。クリップは置かず(作る・動かす・複製の置き先にできない)、連動タスクも作らない。仮歌や DAW で書き出したステムを並べて聞くためのもの。
- **追加**:下端の「オーディオトラックを追加」でファイルを選ぶと、末尾に足す。名前はファイル名(拡張子を除く。重なれば番号を振る)で、名前変更・並べ替え・削除は MIDI のトラックと同じ。選んだファイルが音声として読めなければ、エラーを出して足さない。
- **見出し**:トラック名の下に、音色の代わりにファイル名を出す。押すと別のファイルを選べる(トラックのメニューの「音声ファイルを選び直す」も同じ)。音量・パンのつまみ、ミュート・ソロは MIDI のトラックと同じに効く。リバーブのボタンはない(リバーブは音源の中で掛けるもので、音声には掛けられない)。音量は 100 で元の大きさで、MIDI の音量と同じく2乗の曲線で変わる。
- **音声の区間**:トラックの上に、ファイルの長さぶんの区間を波形付きで出す。横にドラッグすると、鳴らし始める位置が動く(1拍ずつスナップする。Shift を押している間はスナップしない)。フォーカスがあれば ←→ で1拍ずつ、Shift+←→ で1小節ずつ動く。頭は1小節目より前にも出せ、出した分は鳴らさない(カウントや頭の無音を切り捨てる。少なくとも1拍は1小節目より後ろに残す)。タッチでは、クリップと同じく少し長押ししてから動かす。
- 長さは秒のまま持ち、伸び縮みさせない。BPM を変えると区間の幅(小節数)が変わり、小節とずれるが、警告は出さない。位置は曲の頭からの tick で持つので、BPM を変えても「何小節目の何拍目から」は変わらない。
- **ファイルの置き場所**:ファイルの中身は、そのブラウザの IndexedDB(`dtm-proj-audio`。音源と同じく、プロジェクトのデータとは別)に入れる。プロジェクトのデータ(Supabase にも保存される)が持つのは、どのファイルか(id)・ファイル名・サイズ・長さ・位置だけ。だから別の端末や、エクスポートした JSON をインポートした先では、中身がない。
- **中身がないとき**:トラック名の下に「音声なし」、区間は点線で「(このブラウザにありません)」と出す(長さは分かるので、場所は出す)。トラック名の下を押してファイルを選ぶと、同じ id のまま中身を入れる(ほかの端末の中身はそのまま使える)。中身があるファイルを選び直したときは新しい id にするので、ほかの端末では「音声なし」になる。再生では、中身のないトラックを鳴らさず、トーストで知らせる(同じトラックの組み合わせなら、ルーラーを押して鳴らし直すたびには出さない)。WAV の書き出しでは、入れずに書き出すかを先に尋ねる。
- **使わなくなったファイル**:トラックの削除やファイルの選び直しでは、すぐには消さない(トラックの削除はトーストから戻せるため)。アレンジ画面を開いたときに、そのプロジェクトのどのトラックも使っていないものを消す。プロジェクトを消したときは、そのプロジェクトのものをすぐに消す。

## クリップ

- **作成**:トラックの空いているところをドラッグすると、その範囲で作る。ダブルクリックなら1小節。タッチでは、空いているところを少し長押しすると1小節の置き先が出て、そのまま横に動かすと広がり、離すと作る(動かさずに離せば1小節。長押しせずに指を動かすとスクロールになる)。作るとクリップ詳細が開き、すぐ名前を打てる。セクションマーカーの範囲に1小節も重ならない位置には作れない(マーカーが1つもなければ、先に置くよう知らせる)。
- **移動・伸縮**:本体をドラッグ(上下に動かすと別のトラックへ)、左右の端をドラッグで伸縮。動かさずに離すか(端を押したときも)、Enter で詳細が開く。作成と同じく、範囲の外へは動かせない・伸ばせない。タッチでは、クリップを少し長押しして(掴むと半透明になる)からドラッグする。長押しせずに指を動かすと画面のスクロールになり、クリップは動かない(長押しの途中の、指の小さな揺れではやめない)。タッチでは指で掴めるよう、伸縮に使う左右の端を広くとる(クリップの幅の3分の1まで)。
- 同じトラックの中では重ならない。重なる位置に作ろうとしたり、動かしたり伸ばしたりすると、置き先が赤くなり、離しても何も変わらない(元の位置に残る)。別のトラックなら同じ小節に置ける。
- 名前は空でもよく、そのときは「(無題)」と出る。色は連動タスクのステータスに合わせる(ボードのタスクと同じ配色。未着手は青、作業中はオレンジ、完了は緑。無所属の間は点線のまま)。
- **クリップ詳細**(タスク詳細と同じドロワー):名前、詳細、ボードのどのセクションに出ているか、連動タスクのステータス(タスク詳細と同じ3つのボタン)、連動タスクのリファレンス(タスク詳細と同じ欄。どちらで直しても同じタスクのものが変わる)、.mid の読み込みと書き出し、複製、削除(トーストから元に戻せる)。ステータスとリファレンスは無所属の間は出さない。アレンジ画面の右端に最前面で重ねて出し、下の画面(ツールバーや小節)は詰めない(隠れた小節は閉じれば見える)。
- **複数選択**:Ctrl+ドラッグで囲んだクリップを選ぶ(トラックをまたげる。Ctrl+Shift+ドラッグで選択に足す)。Ctrl+クリックで1つずつ選択を切り替え、Ctrl+A で全部を選ぶ。選んだものは点線の枠で出る。選んだものの1つを掴んでドラッグすると、まとめて横に動く(上下には動かない。1つでも重なる位置や範囲の外になるなら、置き先が赤くなり、離しても動かない)。←→ でまとめて1小節ずつ動かす(置けなければ動かない)。Esc か、空いているところや選んでいないクリップを押すと選択を外す。選んだものを動かさずに離すと、選択を外してそのクリップの詳細を開く。
- **複製**:クリップ詳細の「クリップを複製」を押すと、同じ長さの置き先がポインタに付いて動く(トラックをまたげる)。押したところに、名前・詳細・ノートをコピーした別のクリップを作り、その詳細を開く。元のクリップとはつながらない(フォーク。連動タスクも新しく未着手で作られる)。重なる位置やセクションマーカーの範囲の外では置き先が赤くなり、押しても置かない。Esc か右クリック、案内の「取り消し」でやめる。
- **ノートの位置**はクリップの先頭からの相対で持つ。クリップを動かすと(別のトラックへも)ノートも付いていく。左端で伸縮したときは、ノートを曲の中の同じ位置に残す。縮めてクリップの範囲の外(前後)に出たノートは消さずに持ち、鳴らさず、書き出しにも入れない(ピアノロールでは薄く出る。伸ばし直せば戻る)。範囲の終わりをまたぐノートは、終わりで切って鳴らす。
- **小節数**は自動で決まる。いちばん後ろのクリップかマーカーの8小節先までを4小節単位に切り上げて出し、最低32小節。右の余白に置けば、次の表示でさらに伸びる。1小節の幅は固定(テンポを変えても変わらない)。

## セクションマーカー

- ボードのセクション(レーン)を指していて、名前と色はレーンのものを出す(ボードで名前を変えたり並べ替えたりすると、マーカーの表示も変わる)。マーカーの小節から次のマーカーの手前までがそのセクションで、最後のマーカーは右端まで続く。境目はトラックの上にも点線で出る。「全体」レーンは選べない。
- 同じ小節には1つだけ。1つのセクションにもマーカーは1つだけ(置くときと、指すセクションを変えるときに止める。削除の取り消しも、その間に同じセクションを置いていたら戻さない)。以前は同じセクションを何度でも使えたので、そのころのデータの重複は消さずにそのまま扱う(動かす・消すことはできる)。
- マーカーの段の小節を押して、ボードのセクションを選ぶ(すでにマーカーのあるセクションは出ない)。旗を押すと、まだマーカーのないセクションへの変更か削除、横にドラッグで移動。
- 区間にクリップがあるマーカーを動かすと、離したときに「クリップごと動かす」か「マーカーだけ動かす」かを尋ねる(キャンセルで元の位置へ)。区間のクリップは、重なる小節数がいちばん多い区間のもの(同数なら先の区間。重複したマーカーがあっても、別の区間のものは入れない)。クリップごとなら、マーカーと同じだけ横にずらす(ほかのクリップと重なる・1小節目より前に出るなら、その選択肢は押せない)。マーカーだけなら、区間から外れたクリップは、ほかの区間に入らなければ無所属になる。

## 連動タスク

- クリップは、ボードの「トラック名: クリップ名」のタスクとして出る(名前が空なら「(無題)」)。内部では Task に `clipId` を持たせる。名前・詳細・位置はクリップ、ステータス・日付・リファレンス・レーン内の並び順はタスクが持つ。
- 入るレーンは、セクションマーカーの区間と重なる小節数がいちばん多いセクション。重複したマーカーがあれば合計し、同数なら先(左)に出てくるセクション。ボードでは印(Lucide の `audio-lines`)が付く。小節の範囲はボードには出さず、タスク詳細の見出しに出す。
- 新しく作るとレーンの末尾に入る。セクションが変わったときも、移った先の末尾に入る。レーンの中では並べ替えられるが、別のレーンへはドラッグできない(セクションはアレンジで決まる)。
- タスク詳細では、「トラック名:」は固定で、クリップ名と詳細(メモ欄)を直す(クリップのものが変わる)。ステータス・日付・リファレンスはふつうのタスクと同じ。削除は「クリップごと削除」(クリップが残っていると、また作られるため)。トラック名・クリップ名・詳細を変えると、タイトルとメモも変わる。
- **無所属**:マーカーを動かしたり消したりして、どの区間にも重ならなくなったクリップは、その場に残り(点線の枠で出る)、連動タスクはボードにも進捗・ガントチャート・締切パネルの「全タスク完了」にも出なくなる。ただし内部では消さずに持っていて、また区間に入れば、ステータス・日付・リファレンスごと戻る。
- **削除**:ボードでセクションを消すと、そのレーンの連動タスクも消える(元に戻せば状態ごと戻る)。区間にあったクリップは、ほかの区間に入らなければ無所属になり、また区間に入ると未着手のタスクとして作られる。トラックやクリップを消すと、その連動タスクも消える(元に戻せば状態ごと戻る)。
- 連動タスクを揃える処理(`syncClipTasks`)は、アレンジの操作とセクションの削除・取り消しのたびに走る。何度走っても同じ結果になるので、途中で保存に失敗しても次の操作で揃う。Supabase では、そのぶん1操作の通信が増える。

## スケール(転調)

ルーラーの下(セクションの段の上)に「スケール」の段がある。小節を押すと、キー(C〜B)とメジャー / マイナー(自然的短音階)を選んで、そこで転調する(次の転調まで続く)。旗を押すとスケールの変更か削除(元に戻せる)、横にドラッグで移動。1小節目の旗は曲の頭のスケールなので、動かせず消せない(変更はできる)。新しいプロジェクトは1小節目から C メジャー。表記は「C Major」「A Minor」のように英語。教会旋法などは扱わない。ピアノロールの塗り分けだけに使い、再生や書き出しには関わらない。

## 再生

- ツールバーの再生ボタンかスペースキーで、ルーラーで選んだ小節(赤い印)から全体を再生・停止する。ルーラーを押すと開始位置が変わる(再生中ならそこから鳴らし直す。クリップをループで鳴らしている間なら、全体の再生に戻る)。
- スペースキーは、ボタン・クリップ・つまみ・BPM の欄・ピアノロールなど、どこにフォーカスがあっても再生・停止を優先する(ボタンやクリップは Enter で押す・開く)。文字を打つ欄(クリップ名・詳細・リファレンスなど)では空白を打ち、ダイアログを開いている間はダイアログの操作になる。
- 再生中は赤い線が動く(画面の外へ出ても、追いかけてスクロールはしない)。再生中にノート・音色・音量・パン・ミュート・ソロ・リバーブ・音声の位置を変えると、止めずにその先から差し替える(伸びている音は途切れない。消したノートやミュートしたトラックの音は、すぐ止める。音声は、位置を動かしたりミュートを外したりしたときに、いまの位置から鳴らし直す)。BPM を変えたときだけ、いまの位置から鳴らし直す。全トラックをミュートしても、曲の終わりまで再生位置は進む。曲の終わりは、最後のノートと音声の終わりの遅い方。
- BPM はツールバーで変える(20〜300)。
- 音声は、シンセと同じ AudioContext で同じ時刻の基準で予約して鳴らす(ずれない)。音源が選ばれていないと、音声だけでも再生できない。アレンジ画面を開いたときに裏でデコードしておく。ピアノロールのクリップのループ再生では、音声は鳴らさない。
- チャンネルは MIDI のトラックの並び順に 1ch から割り振る(10ch はドラムだけ。オーディオトラックは数えない)。16ch で足りなければ 16ch の組を足し、どのトラックも別のチャンネルで鳴らす(ドラムも1本ずつ、組ごとの 10ch)。.mid の書き出しは 16ch に収めるので、16本目からは使い回し、ドラムはすべて 10ch になる。途中から再生したときは、開始位置より前で始まる音は鳴らさない。

## 編集していない時間

- 再生してばかりで手が止まっていることに気づくための表示。最後に編集してから設定画面で決めた時間(既定は2分。0 なら出さない)が過ぎると、ツールバーの再生の右に「編集から 3:05」のように経過時間を出す。編集すると消えて、0から数え直す。
- 編集は、そのプロジェクトへの保存すべて(ノート、クリップ、トラック、マーカー、スケール、BPM、音色・音量・パン・リバーブ)。ミュート・ソロ(全解除も)は聴くための切り替えなので含めない。再生・停止や選択も含めない。
- 数えるのはアレンジ画面を開いている間だけで、開くたびに0から始める。経過時間はどこにも保存せず、別の端末での編集も見ない。分数はそのブラウザの localStorage に覚える。

## 作業タイマー

- 作業にメリハリをつけるためのもの。進行中のクリップ(連動タスクが作業中のもの。セクションの外のものは除く)を1つずつ「いまの作業対象」にして、決めた時間ごとに次へ進める。PC だけで使い、スマホ(幅 720px 以下か、タッチが主の端末)ではボタンを出さない。
- ツールバーの作業タイマーのボタン(タイマーのアイコン)で始める。ダイアログで、1クリップあたりの時間(分。1〜180、既定は15)と作業する順を決める。時間は前に入れた値をそのブラウザの localStorage に覚えておく。時間はクリップごとには変えない。順は進行中のクリップの一覧で、初めは曲の頭から(同じ小節ならトラックの並び順)。ドラッグで入れ替える。進行中のクリップがなければ、始めずにそう知らせる。
- 動いている間は、ボタンの場所に作業対象のタスク名と残り時間、次へ(`skip-forward`。時間を数え直す)、停止(`square`)を出す。タスク名を押すと、そのクリップを開く。残り1分を切ると、表示の色が変わる。
- 時間切れになると次のクリップへ移って、すぐに数え始める。最後のクリップの時間が終わったら止まる(頭には戻らない)。
- 時間切れは、DAW を前に出して作業しているとブラウザが見えないので、重ねて知らせる。
   - ブラウザにフォーカスがなければ、OS の通知(「次の作業」とタスク名。最後なら、すべて終わったこと)を出す。許可は始めるときに求め、断られたら出さない。通知を押すとブラウザが前に出る。
   - ツールバーの表示を、次にページを触る(クリックかキー)まで点滅させる。
   - タブのタイトルに、いつも残り時間とタスク名を出す(「12:05 ピアノ: コード - DTM工程管理」)。
- 作業対象のタスクを作業中でなくした(完了・未着手にした)ときや、クリップを消したときは、知らせずにすぐ次へ移って数え直す。始めたあとで作業中でなくなったクリップは飛ばし、新しく作業中にしたクリップは入れない。
- アレンジ画面を開いている間だけ動き、ボードなどほかの画面へ移ると止まる。どこにも保存しない。

## 音源

- 設定画面で選んだ SoundFont(.sf2 / .sf3)か DLS(.dls)を、ブラウザの中(spessasynth_lib の AudioWorklet)で鳴らす。ファイルはそのブラウザの IndexedDB(`dtm-proj-soundfont`。プロジェクトのデータとは別)に入れ、エクスポートには含めない。端末・ブラウザごとに1回選ぶ。
- Windows なら `C:\Windows\System32\drivers\gm.dls`(Microsoft GS Wavetable Synth と同じ音色。FL Studio の Fruity LSD もこれを読む)を選ぶのが手軽。ブラウザは決まった場所のファイルを自分では読めないので、自動では使えない。設定画面にパス(コピーのボタン付き)を出し、ファイルを選ぶ画面の「ファイル名」欄に貼り付けて開くよう案内する。Windows 以外では案内を出さず、空のまま選んでもらう。
- 外部の MIDI 音源(Web MIDI)は使わない。Chrome / Edge / Firefox は MSGS を Web MIDI から除外していて鳴らせないため。
- 音源の読み込み(gm.dls は 3MB、GeneralUser GS は 30MB ほど)はアレンジ画面を開いたときに裏で始め、ページを開いている間は使い回す。選ばれていないときに再生を押すと、「設定を開く」のトーストを出す。ツールバーには音源のファイル名(未設定なら「音源を設定」)を出す。ファイル名を押すと「音をリセット」(下記)と「設定を開く」のメニューを出す。
- 読めないファイルを選ぶと、エラーを出して保存しない(前の音源も消える)。
- 再生の重さは、設定画面の「再生の負荷」で変えられる(このブラウザだけに保存。既定と違う値だけを localStorage に覚える)。スマホ(主な入力がタッチの端末)は、既定から軽くしてある。
   - エフェクト(使う / 使わない。既定は使う):spessasynth のリバーブ・コーラス・ディレイの計算。使わないと、トラックのリバーブも掛からない。再生中に変えても、すぐ効く。
   - 同時に鳴らす音(ボイス)の上限(8〜350。既定はスマホが 64、PC が 350 = spessasynth の既定):上限を超えると、古い音・余韻の小さい音から止める。再生中に変えても、すぐ効く。
   - 波形の補間(標準 = hermite / 軽い = linear。既定はスマホが軽い、PC が標準):再生中に変えても、すぐ効く。
   - サンプリング周波数(端末に合わせる / 32 kHz / 22 kHz。既定は端末に合わせる):AudioContext を作るときの値。WAV の書き出しには効かない。
   - 出力のバッファ(小 / 中 / 大 / 特大 = AudioContext の latencyHint の interactive / balanced / playback / 0.3 秒。既定はスマホが特大、PC が小):大きいほど試し弾きの音が遅れる。再生は先読みで予約しているので、タイミングはずれない。
   - サンプリング周波数とバッファは AudioContext を作り直さないと変わらないので、変えると「音をリセット」と同じことをする。
   - いまの状態(サンプリング周波数、出力の遅れ = baseLatency + outputLatency、鳴っている音の数、リセットしてから再生中に鳴った音の数の最大と上限)を出す。開いている間は1秒ごとに出し直す。
- **音をリセット**(設定画面の「再生の負荷」と、アレンジのツールバーの音源の名前から):再生を止め、AudioContext とシンセを捨てて作り直し、音源を読み直す。止まらない音があるときや、しばらく再生しているうちに途切れるようになったときに使う。デコード済みの音声はそのまま使い回す。
- spessasynth_lib(と、WAV の書き出しで使う spessasynth_core)は CDN のファイルなので、Service Worker がキャッシュする。一度鳴らせば(書き出せば)、オフラインでも使える。

## 書き出し

ツールバーの書き出しのボタン(`download`)を押すと、「.mid で書き出す」「.wav で書き出す」のメニューが出る。ファイル名はプロジェクト名。

### .mid

- ツールバーのメニューでアレンジ全体を、クリップ詳細とピアノロールのボタンでクリップ1つ分を書き出す。
- オーディオトラックは入れない。
- フォーマット1。1本目がテンポと拍子、2本目以降がトラック(名前・音色(ドラムならキット)・音量・パン・ノート)。クリップ1つ分なら、クリップの頭が1小節目。

### WAV

- アレンジ全体を、設定画面で選んだ音源で鳴らした音にする。中身は再生と同じ(音色・音量・パン・リバーブと、オーディオトラックの音声。ミュート・ソロも効くので、ソロにしたトラックだけを書き出せる)。16本を超えるトラックも、再生と同じく別々のチャンネルで鳴らす。
- 曲の頭(1小節目)から始め、再生の終わり(ミュートしたトラックの音と、音声の終わりも数える)に残響のぶん2秒を足して終わる。一部のトラックだけを書き出しても長さが揃い、DAW で頭を合わせて並べられる。
- 44.1kHz・16bit・ステレオ。音量は再生と同じで、正規化はしない。
- 実時間を待たずに作る。spessasynth_core の `SpessaSynthProcessor` を Worker の中で動かし(再生用のシンセとは別に、音源ファイルをもう1つ読み込む)、ノートをサンプル単位の位置で送る。音声は Worker の中ではデコードできないので、画面の側で 44.1kHz にデコードして渡し、シンセの音を作ったあとに足し込む(音量・パンは再生の StereoPannerNode と同じ式)。作っている間は、進み具合(%)を出す。
- 鳴らす音がない(ノートも音声もない、すべてミュート)ときと、音源が選ばれていないとき(「設定を開く」のトースト)は書き出さない。

## .mid の読み込み

- クリップ詳細の読み込みのボタン(`upload`。書き出しのボタンの左)か、ピアノロールのヘッダーのメニュー(`ellipsis-vertical`)の「.mid を読み込む」で .mid を選ぶと、そのクリップのノートを丸ごと置き換える。FL Studio のピアノロールから書き出した、1トラックのものを想定している。ファイルのドロップと、アレンジ全体(トラックやクリップを作る)の読み込みはない。
- 読み込むのはノート(高さ・位置・長さ・ベロシティ)だけ。ファイルの頭(tick 0)をクリップの頭に合わせ、位置はファイルの時間単位(FL Studio は 96 tick)から換算する。テンポは使わない(BPM はプロジェクトのまま)。CC・ピッチベンド・プログラムチェンジなどは読み込まず、あればトーストで知らせる。4/4 以外の拍子のファイルも 4/4 として読み、トーストで知らせる。
- ノートのあるトラックが複数ある(1本のトラックに複数のチャンネルがあるときは、チャンネルごとに分ける)と、名前とノート数の一覧から1つを選ぶ。
- ノートがクリップに収まらないときは、「クリップを N 小節に伸ばす」か「長さはそのまま」かを尋ねる。伸ばすのは移動・伸縮と同じく、ほかのクリップと重なる・セクションマーカーの範囲の外に出るならできない(ボタンが押せない)。そのままなら、はみ出したノートは消さずに持ち、鳴らさない。
- 読み込んだあとのトーストから元に戻せる(置き換える前のノートと長さに戻す)。
- フォーマット0 / 1 を読む。フォーマット2、SMPTE の時間単位、壊れたファイル、ノートのないファイルはエラーのトーストを出して何もしない。
